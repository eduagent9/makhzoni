# مخزوني

تطبيق ويب عربي لإدارة متجر صغير، بواجهة RTL متجاوبة وبيانات محلية على الجهاز.

## التشغيل
انشر محتويات المستودع على استضافة HTTPS (أو localhost). افتح الرابط على الهاتف ويمكن تثبيته كتطبيق. ملف Service Worker يهيئ الملفات الأساسية للعمل دون اتصال بعد أول تحميل ناجح.

## الوظائف الموجودة
- المنتجات: الاسم والتصنيف وSKU والباركود وأسعار الشراء والبيع والكمية وحد التنبيه وصورة محلية مضغوطة وتاريخ انتهاء الصلاحية.
- صور المنتجات تُضغط داخل المتصفح وتُحفظ مع بيانات التطبيق محلياً؛ لا تُرفع إلى خادم.
- المبيعات: فاتورة متعددة الأصناف، خصم تلقائي للمخزون، تخفيض، مدفوع/متبقي، تسجيل دفعات إضافية وطباعة الفاتورة.
- الباركود: إدخال/لصق الرمز للبحث عن المنتج، ومسح بالكاميرا في المتصفحات الداعمة مع إذن الكاميرا وHTTPS.
- المشتريات: تسجيل المورد والكمية وتحديث المخزون.
- سجل الموردين والمصاريف.
- سجل الزبائن مع كشف حساب لكل زبون، رصيد الديون، والفواتير والدفعات المتبقية.
- تحويل المخزون بين المخزن الرئيسي والفروع مع سجل تاريخي وأرصدة مستقلة لكل موقع.
- المرتجعات: مرتجع البيع يعيد الكمية ومرتجع الشراء يخصمها.
- الجرد: إدخال الكمية الفعلية وتسجيل فرق المخزون.
- لوحة مؤشرات وتنبيهات المخزون المنخفض، وتقرير إجمالي للربح التقريبي والديون غير المدفوعة.
- إغلاق الصندوق اليومي.
- تصدير المنتجات والمبيعات والمشتريات والمصاريف والمرتجعات CSV ونسخة احتياطية JSON واسترجاعها.
- طباعة الفواتير والتقارير من المتصفح، مع إمكانية اختيار Save as PDF من نافذة الطباعة.
- إعداد اسم المتجر والعملة المغربية (درهم)، وتهيئة PWA للعمل دون اتصال بعد التحميل الأول.

## التخزين والخصوصية
يستخدم التطبيق Local Storage ولا يرسل بيانات إلى خادم أو API. البيانات مرتبطة بالمتصفح والجهاز؛ نزّل نسخة JSON بانتظام. حذف بيانات المتصفح قد يؤدي إلى فقدانها. مسح الباركود بالكاميرا يتطلب منح إذن الكاميرا للمتصفح.

## ملاحظات مهمة
هذه نسخة أولية. لم تُنفذ بعد مزامنة الأجهزة، حسابات متعددة المستخدمين، قفل PIN، PDF/Excel متقدم، وإدارة مخزون متعدد المستودعات. اختبر العمليات على بيانات تجريبية قبل اعتمادها تجارياً، وراجع الحسابات والفواتير.
