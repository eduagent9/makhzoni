# مخزوني

تطبيق ويب عربي لإدارة متجر صغير، بواجهة RTL متجاوبة وبيانات محلية على الجهاز.

## التشغيل
انشر محتويات المستودع على استضافة HTTPS (أو localhost). افتح الرابط على الهاتف ويمكن تثبيته كتطبيق. ملف Service Worker يهيئ الملفات الأساسية للعمل دون اتصال بعد أول تحميل ناجح.

## الوظائف
- المنتجات: الاسم والتصنيف وSKU والباركود وأسعار الشراء والبيع والكمية وحد التنبيه وتاريخ انتهاء الصلاحية.
- المبيعات: فاتورة متعددة الأصناف، خصم تلقائي للمخزون، تخفيض، مدفوع/متبقي، تسجيل دفعات إضافية وطباعة الفاتورة.
- الباركود: إدخال الرمز أو مسحه بالكاميرا في المتصفحات الداعمة مع إذن الكاميرا وHTTPS.
- المشتريات والموردون والمصاريف والمرتجعات والجرد وإغلاق الصندوق اليومي.
- لوحة تحكم تشمل مبيعات اليوم وهامش الربح وقيمة المخزون والديون وتنبيهات المخزون المنخفض.
- صفحة ديون الزبائن مع تسجيل الأداءات المتبقية.
- سجل حركات المخزون عند تغيّر كميات المنتجات.
- تنبيهات المنتجات المنتهية أو التي ستنتهي خلال 30 يوماً.
- إحصائيات شهرية لآخر 6 أشهر تشمل المبيعات والتكلفة والمصاريف والربح وهامش الربح.
- صلاحيات محلية للمالك والبائع؛ البائع محدود في متابعة المنتجات وتسجيل المبيعات والدفعات.
- تصدير البيانات CSV المتوافق مع Excel، ونسخة احتياطية JSON واسترجاعها.
- طباعة الفواتير والتقارير من المتصفح، مع إمكانية اختيار Save as PDF من نافذة الطباعة.

## التخزين والخصوصية
يستخدم التطبيق Local Storage ولا يرسل بيانات إلى خادم أو API. البيانات مرتبطة بالمتصفح والجهاز؛ نزّل نسخة JSON بانتظام. حذف بيانات المتصفح قد يؤدي إلى فقدانها. لا توجد مزامنة بين الأجهزة.

رموز PIN الخاصة بالأدوار تحفظ محلياً في المتصفح وهي لتنظيم الصلاحيات فقط، وليست نظام مصادقة آمناً ضد شخص لديه وصول تقني إلى الجهاز أو المتصفح.

## ملاحظات
هذه نسخة تطويرية. اختبر العمليات على بيانات تجريبية قبل اعتمادها تجارياً، وراجع الحسابات والفواتير. CSV يفتح في Excel، لكنه ليس ملف XLSX أصلياً.
