# مخزوني

تطبيق ويب عربي لإدارة متجر صغير، بواجهة RTL متجاوبة وبيانات محلية على الجهاز.

## التشغيل
انشر محتويات المستودع على استضافة HTTPS (أو localhost). افتح الرابط على الهاتف ويمكن تثبيته كتطبيق. ملف Service Worker يهيئ الملفات الأساسية للعمل دون اتصال بعد أول تحميل ناجح.

## الوظائف الموجودة
- المنتجات: الاسم والتصنيف وSKU والباركود والأسعار والكمية وحد التنبيه.
- المبيعات: تسجيل بيع، خصم المخزون، رقم فاتورة وطباعة فاتورة.
- المشتريات: إضافة كمية للمخزون مع المورد والمرجع.
- سجل الموردين والمصاريف.
- المرتجعات: مرتجع البيع يعيد الكمية ومرتجع الشراء يخصمها.
- لوحة مؤشرات وتنبيهات المخزون المنخفض.
- تقارير إجمالية وإغلاق الصندوق اليومي.
- تصدير المنتجات والمبيعات CSV ونسخة احتياطية JSON واسترجاعها.
- إعداد اسم المتجر والعملة.

## التخزين والخصوصية
يستخدم التطبيق Local Storage ولا يرسل بيانات إلى خادم أو API. البيانات مرتبطة بالمتصفح والجهاز؛ نزّل نسخة JSON بانتظام. حذف بيانات المتصفح قد يؤدي إلى فقدانها.

## غير منفذ بعد
قراءة الباركود بالكاميرا، أكثر من صنف في الفاتورة الواحدة، PDF/Excel متقدم، إدارة الزبائن والديون، مزامنة الأجهزة، وقفل PIN. هذه نسخة أولية وليست نظاماً محاسبياً معتمداً؛ راجع الحسابات قبل اعتمادها تجارياً.
